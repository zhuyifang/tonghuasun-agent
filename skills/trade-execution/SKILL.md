# 同花顺实盘交易代理

FQGate 默认隐藏真实资金写工具。只有用户自行在 FQGate 主界面开启“委托下单”或“资金划转”后，对应工具才会出现；工具可见不等于用户授权任何操作。

交易账户、资产和记录只能来自当前 AI 工具加载的 `fqgate` MCP。工具失败时不得用估算、网页数据或旧对话内容替代。

## 账户查询

### 决策规则

- 查询交易数据时使用当前有效 `sessionId` 调用 `fqgate_trade_trading_accounts`，并沿用返回的 `accountId` 与 `tradingMode`。
- 只有一个已认证账户且用户没有限制账户类型时可直接查询；存在多个普通或信用账户时，展示脱敏后的候选项并让用户选择。
- 资产、持仓、委托、成交等使用范围最窄的对应工具。用户指定日期时直接传日期范围，不先拉取大量历史记录再筛选。
- 所有后续调用沿用同一登录会话返回的三元组，不根据账号显示文本拼接 `sessionId`、`accountId` 或 `tradingMode`。
- 只展示回答问题所需的字段；完整账号、会话标识及其他无关敏感内容必须隐藏或脱敏。

### 常见查询

- “我还有多少可用资金”：`fqgate_trade_trading_accounts` → 选择账户 → `fqgate_trade_assets`。
- “我持有哪些股票/盈亏多少”：账户确认 → `fqgate_trade_positions`，需要汇总时明确区分工具字段和 AI 计算。
- “今天是否成交/订单还在吗”：账户确认 → `fqgate_trade_orders` 和/或 `fqgate_trade_trades`，按合同编号或证券过滤。
- “查上月流水/交割单”：账户确认 → `fqgate_trade_fund_flows` 或 `fqgate_trade_settlements`，传完整开始与结束日期。
- “查银行卡/银证记录/担保品”：账户确认 → `fqgate_trade_bank_accounts`、`fqgate_trade_bank_transfers`、`fqgate_trade_collateral_securities` 或 `fqgate_trade_collateral_transfer_flows`。

### 交易登录

- 行情扫码登录不登录券商交易账户，也不能产生交易 `sessionId`。
- 没有有效交易会话时，不要求用户把资金账号、交易密码或短信验证码发到聊天中；优先请用户在 FQGate 本机界面完成交易登录后再继续。
- `fqgate_trade_login` 需要敏感参数。只有当前 AI 工具提供安全的本机交易登录界面并由用户在场操作时才能使用；否则不得在聊天中收集凭据。
- 当前没有对应界面时，不声称已经提供资产、持仓或交易登录面板。

## 决策规则

- “能不能买”“该不该卖”“还能不能持有”属于行情判断，使用“同花顺免费实时数据代理”取得行情和走势，不调用写工具。
- 先用只读账户工具取得有效 `sessionId`、`accountId`、`tradingMode` 和目标业务所需原始标识；不得从显示文本猜测。
- 按当前工具 schema 或 `fqgate://openapi` 准备参数，不自行补价格、数量、市场、股东账户、银行、币种或交易方向。
- 为本笔操作生成新的 `idempotencyKey` 或 `clientRequestId`，在确认前连同所有关键参数展示给用户。
- 收到明确确认后只调用一次对应写工具，并保持参数逐字一致。任何参数变化都必须重新展示并重新确认。
- 写入返回后使用只读记录核实最终状态；“已受理”不等于成交、到账、配号或最终成功。

## 典型调用链

1. 查询交易账户与必要的持仓、委托、银行或担保品信息。
2. 选择唯一目标账户，校验工具仍可用且所有必填参数已确定。
3. 展示单笔确认摘要并停下来询问用户确认。
4. 用户明确确认后调用一次：
   - 下单：`fqgate_trade_place_order`
   - 撤单：`fqgate_trade_cancel`
   - 新股申购：`fqgate_trade_subscribe_ipo`
   - 银证转账：`fqgate_trade_transfer_bank`
   - 担保品划转：`fqgate_trade_transfer_collateral`
5. 查询委托、成交、转账或划转记录，报告可验证状态。

## 单笔确认内容

- 下单：账户、交易模式、买卖或业务类型、证券、市场、价格类型与价格、数量、`idempotencyKey`。
- 撤单：账户、交易模式、目标委托合同编号、市场、股东账户、信用撤单所需原始字段、`clientRequestId`。
- 新股申购：账户、交易模式、申购代码、市场、股东账户、发行价格、数量、`clientRequestId`。
- 银证转账：账户、银行、币种、转入或转出方向、金额、实际认证要求、`clientRequestId`。
- 担保品划转：信用账户、证券、划入或划出方向、数量、`clientRequestId`。

确认只能针对当前一笔确定操作，不能复用于后续交易、批量操作或参数变化后的请求。“继续”“按之前的来”仅在当前摘要仍完整可见且参数没有变化时有效；有任何歧义都应重新确认。

## UI 与授权边界

- 行情登录 UI 不负责券商登录、交易参数确认或交易授权，不得把扫码成功视为允许交易。
- 当前没有可替代聊天内逐笔确认的交易 UI。即使客户端展示行情、持仓或其他组件，也必须在调用写工具前取得本笔明确确认。
- 不让用户在聊天中提供交易密码、短信验证码等认证信息。需要认证且当前客户端没有安全输入界面时停止，请用户在 FQGate 或券商正式界面完成。

## 停止条件与防重

- 写工具不可见、会话失效、账户不匹配、必填参数缺失、用户确认含糊或确认后参数变化时停止，不调用工具。
- 超时、连接中断或结果未知时禁止自动重试，也不得复用操作编号。先查询对应记录，仍不能确定时请用户到券商正式渠道核对。
- 工具明确拒绝后不自动改价、改量、换账户、拆单或重试；展示原因并等待用户新指令。
- 不执行用户没有逐笔确认的批量下单、自动追单、自动撤单、循环转账或无人值守交易。

## 账户数据安全

- 缺少有效 `sessionId`、账户选择不明确或会话失效时停止查询，等待用户登录或选择。
- 权限未开启、工具不存在、返回账户不匹配或查询范围被券商拒绝时，报告可理解的原始原因，不改用其他账户重试。
- 不回显密码、验证码、完整资金账号或完整会话标识，不把账户数据写入文件或长期保存，除非用户另有明确请求和授权。
