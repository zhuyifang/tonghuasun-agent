# 在豆包中安装同花顺 Agent

豆包需要同时启用本机同花顺插件、“同花顺 Agent”技能和同名连接器。安装程序会处理本机插件和技能；连接器已经创建过就会直接复用，首次使用只需在豆包中创建一次。

## 一句话安装

从 [GitHub 最新版下载页](https://github.com/zhuyifang/tonghuasun-agent/releases/latest) 或 [Gitee 发行版下载页](https://gitee.com/qicuo/tonghuasun-agent/releases) 下载 `tonghuasun-agent-doubao-版本号.zip` 并解压，把解压后的文件夹添加到豆包“工作任务”，选中“同花顺 Agent”技能和连接器，然后发送：

> 直接运行这个目录中的 `setup.ps1` 安装同花顺 Agent 豆包插件，已有设置请直接复用；安装完成后只通过同花顺 Agent 连接器查询工业富联今天的行情，查询成功即停止。

安装程序会先检查当前电脑上的同花顺 Agent：版本已经一致时不会重复安装，也不会要求退出同花顺；只有确实需要安装、更新或修复本机插件时，才会提示你先正常退出同花顺。豆包技能安装后会自动同步，无需重启豆包。

使用“按需确认”时，豆包会在运行安装程序前请你允许一次。如果希望安装过程不中断，可以只在本次安装任务中选择“全部允许”，安装完成后再恢复“按需确认”。

## 首次创建连接器

豆包的连接器保存在你的豆包账号中，因此首次使用需要在豆包界面确认一次。已有名为“同花顺 Agent”的连接器时，不要重复创建，但每个新工作任务仍需选中该连接器才能调用。

1. 打开豆包的“技能 · 连接器 · 伙伴”，新建名为“同花顺 Agent”的自定义连接器。
2. 选择“连接方式：HTTP”，填写下面三项并保存：

| 项目 | 填写内容 |
| --- | --- |
| 地址 | `http://127.0.0.1:17180/mcp?textCompatibility=true` |
| 请求头名称 | `X-Tonghuasun-Codex-Token` |
| 请求头内容 | 本机 API 访问令牌 |

在 PowerShell 中运行下面的命令，可以查看本机 API 访问令牌：

```powershell
(Get-Content "$env:LOCALAPPDATA\TonghuasunCodex\config.json" -Raw | ConvertFrom-Json).localAccessToken
```

请只复制命令返回的令牌，不要把令牌公开到聊天、截图或 Issue 中。

## 验证安装

新建豆包工作任务，同时选中“同花顺 Agent”技能和连接器，然后发送：

> 使用同花顺 Agent 查看航天机电最新 5 条实时逐笔委托，只返回委托时间、方向、价格和数量。

返回本机同花顺远航版中的数据即表示安装成功。连接器会直接访问本机接口，不需要另外启动代理程序。

## 手动安装

如果豆包没有运行安装程序，请在解压目录中手动运行：

```powershell
.\setup.ps1
```

安装本机插件或技能时出现明确错误，按屏幕提示处理后重新运行即可。安装程序不会覆盖内容不同的同名技能。

## 常见问题

### 本机接口文档打不开

请确认同花顺已经启动并完成登录。如果仍然打不开，请重新运行 `setup.ps1 -RepairClient`；只有需要修复本机插件时才需要先退出同花顺。

### 连接器提示 401 或无权访问

请重新获取本机 API 访问令牌，确认请求头名称和令牌内容没有多余空格。

### 豆包改用自带金融数据源

请新建工作任务，并确认“同花顺 Agent”技能和连接器都已选中。豆包回答“当前金融数据源不支持逐笔委托”时，通常表示它没有调用本机连接器。

### 返回内容不完整

请确认连接器地址末尾保留了 `?textCompatibility=true`。该参数用于让豆包完整读取工具返回的数据。

## 更新插件

下载并解压新版豆包安装包，再发送同一句安装指令即可。安装程序会复用已有连接器，只更新确实发生变化的本机插件和豆包技能。
