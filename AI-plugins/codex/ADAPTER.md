## Codex 适配

- 本插件已启用且请求属于 FQGate 能力时，优先通过名为 `fqgate` 的本机 MCP 获取数据，不先改用内置金融数据或网络搜索。
- 首次配置或连接失败时使用“同花顺免费实时数据代理”，不要改写用户的全局 MCP 配置。
- 工具返回 `structuredContent` 时优先读取结构化内容；只有没有结构化内容时才使用同一结果中的文字内容。
- 工具结果带有现有界面且 Codex 能够显示时，直接展示该界面，不为 Codex 另写或复述一份页面布局。
- 界面未显示或加载失败时，使用同一次工具结果给出简洁文字结论；不要为了取得界面或文字副本重复调用工具。
