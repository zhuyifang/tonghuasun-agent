# 公共界面组件

不同 AI 工具共用的业务界面放在这里。组件只依赖 `shared` 中的公共约定，不直接依赖某个厂商。

业务组件原则上使用 `width: 100%` 占满容器，由调用方决定最终展示宽度。

当前组件：

- `login/`：行情扫码与短信验证码登录。
- `candle/`：个股行情、分时、五日走势、多周期 K 线，以及按账户权限选择 Level-2 或普通行情的盘口与成交明细。
- `information/`：由 AI 工具调用结果驱动的通用资讯列表，不包含查询类型切换和数据源逻辑。
- `market-quotes/`：批量快照、实时推送和日内走势的多股行情面板。
- `order-flow/`：Level-2 实时逐笔委托与撤单面板，包含普通行情回退和按可见性管理实时连接。
