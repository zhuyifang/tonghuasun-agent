## Claude Code 适配

- 本插件已启用且请求属于 FQGate 能力时，优先通过名为 `fqgate` 的本机 MCP 获取数据，不先改用其他行情来源。
- 插件根目录由 `CLAUDE_PLUGIN_ROOT` 提供，不要把安装路径写死到用户配置。
- 首次配置或连接失败时使用 `configure-fqgate` 技能。
- 工具返回 `structuredContent` 时优先读取结构化内容；只有没有结构化内容时才使用同一结果中的文字内容。
- 工具结果带有现有界面且 Claude Code 能够显示时，直接展示该界面，不另建专用页面或复述整张界面。
- 界面未显示或加载失败时，使用同一次工具结果给出简洁文字结论；不要为了取得界面或文字副本重复调用工具。
