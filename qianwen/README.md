# 在千问中安装同花顺 Agent

安装完成后，你可以在千问中直接查询当前电脑上的同花顺行情、Level2、短线精灵、持仓、委托和成交数据。

## 安装前准备

- 使用 Windows 10 或 Windows 11，并已安装、登录同花顺远航版。
- 使用千问电脑客户端，并至少进入过一次“工作任务”。
- 从 [GitHub 最新版下载页](https://github.com/zhuyifang/tonghuasun-agent/releases/latest) 或 [Gitee 发行版下载页](https://gitee.com/qicuo/tonghuasun-agent/releases) 下载 `tonghuasun-agent-qianwen-版本号.zip`，然后解压。

## 让千问自动安装

把解压后的文件夹添加到千问“工作任务”，然后发送：

> 请阅读当前目录的 README.md，运行 setup.ps1 自动完成安装；需要退出同花顺或确认系统授权时再提示我，不要让我手动执行命令。

安装程序会先检查当前电脑上的同花顺 Agent：已经是当前版本时不会重复配置，也不需要退出同花顺；只有首次安装、需要升级或主动修复时，才会提示你正常退出同花顺。千问写入新工具后会重新加载一次，在当前任务中看到“AgentRuntime 已变化”属于正常现象，等待加载完成后新建工作任务即可。

## 手动安装

如果自动安装没有完成，在解压目录中只需运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
```

如果提示需要安装或更新本机同花顺插件，请正常退出同花顺后再次运行同一条命令。安装完成后重新启动同花顺；千问提示正在重新加载工具时，等待完成后新建工作任务。只有新任务仍未显示同花顺工具时，才需要退出并重新打开千问。

## 验证

在千问的新工作任务中发送：

> 使用同花顺 Agent 查看航天机电最新 5 条实时逐笔委托，只返回委托时间、方向、价格和数量。

如果返回了当前电脑同花顺中的逐笔委托数据，说明安装成功。

## 常见问题

### 千问仍然使用内置金融数据

请确认使用的是“工作任务”，并新建一个任务后重试。正确安装后，千问会优先调用 `tonghuasun-agent` MCP；如果 MCP 调用失败，它应直接提示检查本机插件，而不是改用内置金融数据代替。

### 提示“AgentRuntime 已变化”

这表示千问刚刚重新加载了工具，不是安装失败。等待提示消失后新建工作任务即可；不要在安装前已经打开的页面中反复验证。重复运行同一版本的安装程序不会再次改写千问配置。

### 提示插件文件映射不健康

先打开 [本机接口健康检查](http://127.0.0.1:17180/health)。如果页面显示运行正常且版本与安装包一致，安装程序会直接保留当前本机插件，只安装千问入口；不需要因为旧校验记录重复部署。只有健康检查无法打开、版本较旧或数据访问不可用时，才需要退出同花顺并重新配置。

### 本机接口无法访问

请确认同花顺已经重新启动并完成登录，然后打开 [本机接口文档](http://127.0.0.1:17180/docs)。页面无法打开时，请重新配置本机同花顺插件。

### 返回内容不完整

千问插件已经启用文字兼容输出。查询 Level2 明细时，请在问题中直接说明需要的条数，例如“最新 5 条”或“最近 20 条”，千问会把数量传给接口。

## 更新或卸载

更新时下载新版千问安装包并重新运行 `setup.ps1`。如果本机插件也需要更新，安装程序会提示退出同花顺；只更新千问入口时不需要退出同花顺。千问中新建工作任务即可加载新版技能。

只卸载千问入口时运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1 -Uninstall
```
