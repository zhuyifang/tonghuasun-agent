# AI 工具调用路由评测

这套评测用例用于检查 AI 是否能根据用户的自然语言请求，选择正确的 FQGate 技能、工具、调用顺序和界面，并遵守登录、权限与真实交易的安全边界。

首轮用例位于 `tests/fixtures/ai-tool-routing-evals.json`，覆盖以下场景：

- 当前行情、证券搜索和自选字段查询；
- K 线、分时和均线分析；
- 个股资讯和重大事件；
- Level-2 逐笔、撤单、盘口和委托队列；
- 资产、持仓、委托、成交、资金流水和交割单；
- 扫码登录、短信登录、本机快捷登录和交易账户登录；
- 下单、撤单、新股申购、银证转账和担保品划转；
- 连接失败、权限不足、结果未知和持续订阅边界；
- 登录、K 线、资讯、行情和逐笔委托界面的展示。

## 每条用例怎么看

- `prompt`：用户可能直接说出的一句话。
- `expectedSkill`：应由哪个公共技能处理。
- `expectedTools`：应调用的工具。`ordered` 表示固定顺序，`oneOf` 表示多条顺序都可以接受，`none` 表示当前请求不应调用工具。
- `expectedUi`：应展示的界面；`null` 表示不要求展示界面。
- `forbidden`：即使用户提出要求，也不能执行的替代、猜测、越权或危险行为。

## 运行检查

在仓库根目录执行：

```powershell
npm test
```

检查会确认用例数量和格式、九类场景覆盖、技能和工具引用、五个界面入口，以及登录与交易的重要安全要求。整个过程只读取仓库文件，不连接网络，不调用 AI 服务，也不会访问真实账户。

这份评测是后续接入不同 AI 工具时的共同基线。界面、技能或工具发生变化后，应同步更新对应评测，避免某个入口出现与其他入口不同的行为。
