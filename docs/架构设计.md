# tonghuasun-agent 架构

## 运行方式

Codex、Claude Code、WorkBuddy、ZCode、OpenClaw、DeepSeek Harness、豆包和千问使用各自的插件入口，通过本机 MCP 连接
同一个同花顺服务。

```text
Codex ────────────────┐
Claude Code ───────────┤
WorkBuddy ────────────┼─ MCP 传输桥 ─ 本机同花顺服务 ─ 同花顺
ZCode ────────────────┤
OpenClaw ─────────────┤
DeepSeek Harness ─────┤
豆包 ─────────────────┤
千问 ─────────────────┘
```

行情、账户和交易能力由本机同花顺服务提供。八个 Agent 入口只负责安装、配置和
连接，不各自维护证券业务接口。

## 仓库目录

```text
tonghuasun-agent/
  codex/               Codex 插件清单
  claude-code/         Claude Code 插件清单
  workbuddy/           WorkBuddy 插件清单
  zcode/               ZCode 插件清单
  openclaw/            OpenClaw Agent Plugins 清单
  deepseek-harness/    DeepSeek Harness 插件清单
  doubao/              豆包连接器与技能说明
  qianwen/             千问 MCP、技能与安装入口
  tonghuasun-mcp/
    tooling/           配置器、传输桥和界面构建工具
    distribution/      公共发行文件与统一 MCP 使用规范
    legal/             许可证和法律声明
```

C# 开发的同花顺本机插件暂时闭源，发行版以已编译组件提供。

工具选择、参数规则、数据口径和交易边界只在
`tonghuasun-mcp/distribution/skills/tonghuasun-agent/SKILL.md` 维护。每个 Agent
目录只保存该客户端专用的 `ADAPTER.md`；发行脚本生成安装包时，将公共规范与专属
片段合成为最终 `SKILL.md`，避免不同插件的说明逐渐产生差异。动态字段的完整含义
以本机接口文档为准，公共技能只负责引导 AI 查询文档，不在各入口复制字段表。

## 本机连接

同花顺服务只登记 `127.0.0.1` 和当前电脑的私有 IPv4 局域网地址，不使用 `+`、`*`
或公网地址。局域网入口只允许同一子网来源，并由 Windows 防火墙限制在专用网络或
域网络；配置器会生成随机访问令牌，并把端口、令牌、监听地址和运行时地址保存在
`%LOCALAPPDATA%\TonghuasunCodex`。

MCP、REST 和 WebSocket 使用同一套数据与权限检查。Python SDK 读取相同的运行时
配置，因此无需在代码中写死端口或访问令牌。

## 更新和卸载

更新、修复或卸载本机插件前，应先正常退出同花顺。配置器只处理由本项目安装并能
确认归属的文件，不删除其他同花顺文件。

## 交易安全

交易工具默认关闭。启用后，交易请求先生成预览，确认时不能修改原始证券代码、
价格、数量或账户。下单、撤单和改单还需要同花顺桌面确认。无人值守 REST 交易
使用独立开关，不会因为启用 Agent 交易工具而自动开启。
