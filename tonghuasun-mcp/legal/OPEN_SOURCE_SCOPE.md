# 开源范围

## AGPL-3.0-only 范围

- `.claude-plugin/**`
- `codex/**`
- `claude-code/**`
- `workbuddy/**`
- `zcode/**`
- `openclaw/**`
- `deepseek-harness/**`
- `tonghuasun-mcp/tooling/**`
- `tonghuasun-mcp/distribution/**` 中由本项目公开的脚本、界面和 SDK 源码
- 仓库中的公开文档和构建脚本

以上源码的修改版和衍生版在传播或通过网络向用户提供服务时，应按 AGPL-3.0
提供对应源码，并保留 `ADDITIONAL_TERMS.md` 指定的合理署名。

## 不在本许可证范围

以下内容不因存放或分发在本仓库中而自动获得 AGPL 授权：

- `tonghuasun-mcp/distribution/payload/ths-plugin/ThsPlugin.*` 闭源原生运行组件；
- 第三方组件及其许可证文本；
- 私有调试资料、签名密钥和本机运行凭据；
- 赞助者头像、收款码和交流群二维码等个人图片。

上述内容分别适用权利人许可、`NATIVE_COMPONENT_LICENSE.md`、
`PROPRIETARY_COMPONENTS.md` 和 `THIRD_PARTY_NOTICES.md`。
