# 隐私政策

更新日期：2026 年 8 月 27 日

这份说明告诉你，同花顺 Agent 会在什么地方处理数据，以及哪些网络连接是功能正常运行所必需的。

## 插件不会向项目维护者上传证券数据

本项目不运营用于接收行情、账户或交易数据的远程服务器。

插件从你电脑上的同花顺客户端读取数据，在本机完成整理，并通过本机接口交给当前电脑上调用它的 AI 助手或程序。行情、账户、持仓、委托、成交和资金数据不会上传给项目维护者。

本机 MCP、REST API 和 WebSocket 接口只接受当前电脑的访问，并使用安装时随机生成的本机访问令牌。

## 必要的网络连接

以下连接不属于向项目维护者上传证券数据：

- 同花顺客户端会按其自身功能连接同花顺、证券公司或相关数据服务；使用问财时，查询内容会发送给同花顺服务。
- 插件会从 GitHub 或 Gitee 获取公开版本信息。该请求不包含行情、账户或交易内容，但网站和网络服务仍可能看到 IP 地址、插件版本等常规请求信息。
- 如果你使用云端 Agent 或模型服务，AI 助手可能把你的问题和工具返回结果发送给相应服务。该过程由你选择的服务及其隐私政策负责，不由本项目控制。

## 保存在本机的数据

为了完成安装、连接和故障排查，本机可能保存：

- 插件配置、本机访问令牌和随机设备标识；
- 当前端点、版本检查状态和已安装版本文件；
- 交易功能开启后用于防止重复下单的本机记录；该记录只保存请求标识的哈希、参数指纹和执行状态，不保存完整账户或委托参数；
- 诊断日志。

诊断日志会记录接口类型、运行状态、数量、证券代码、问财查询内容或错误摘要。正常运行产生的交易诊断摘要不包含账户标识、资金金额、持仓明细、委托价格、委托数量和合同编号；密码和完整访问令牌也不会写入日志。部分错误摘要可能来自第三方组件，分享日志前仍请检查其中是否包含个人信息。

这些文件不会由本项目自动上传。

## 删除本机数据

卸载插件会移除由安装器管理的同花顺插件文件。若还要删除本机配置、令牌、版本文件和诊断日志，请先退出同花顺，再删除：

```text
%LOCALAPPDATA%\TonghuasunCodex
```

删除后再次安装会生成新的本机访问令牌。

## 保护自己的数据

请不要公开本机访问令牌，也不要在 Issue、聊天记录或日志附件中提交证券账号、资金账号、完整持仓和交易明细。不要把本机接口转发到公网，也不要交给不受信任的程序使用。

任何软件都无法保证绝对安全。发现安全问题时，请使用 [GitHub 私密安全报告](https://github.com/zhuyifang/tonghuasun-agent/security/advisories/new) 联系维护者，不要公开披露令牌、账户或漏洞利用细节。

## 政策更新

重要变化会在仓库提交记录或发行说明中公布。法律要求另行告知或取得同意的，按相应要求执行。
