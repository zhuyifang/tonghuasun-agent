# 使用条款

更新日期：2026 年 8 月 27 日

## 项目性质

同花顺 Agent 是独立开发的非官方本机工具，与同花顺及其关联公司、证券公司和交易所不存在授权、合作、联合运营或背书关系。

项目用于把你电脑上已经安装并登录的同花顺客户端连接到你选择的 AI Agent 或本机程序。项目不提供同花顺账户、证券账户或额外的数据权限，也不会绕过登录、付费权限、数据访问限制或交易确认。

你能使用的数据和功能，取决于自己的账户、客户端版本及已经开通的服务权限。使用本项目时，你仍需遵守同花顺、证券公司、交易所、行情服务和 AI 服务的相关协议与规则。

## 所有功能免费开放

本项目不设置订阅、会员、套餐、试用额度或付费解锁。自愿赞赏不用于购买功能、数据权限、投资建议、问题处理优先级或后续服务承诺。

## 不是投资建议

本项目是一项数据连接和展示工具，不提供个股推荐、买卖建议、收益预测、收益保证、代客理财或证券交易邀约。

AI 根据数据生成的内容可能存在错误、遗漏或延迟。任何投资和交易决定都应由你独立判断，最终行情、资产、委托和成交状态以同花顺、证券公司及交易所的正式记录为准。

## 交易功能

交易工具默认关闭。只有你主动开启后，相应工具才会出现；通过 Agent 下单、撤单或改单时，会先显示交易内容并等待你确认，随后仍需经过同花顺的交易流程。开启交易工具不等于授权任何一笔交易，仅查询行情和账户数据不会发起交易。

无人值守 REST 交易使用独立开关，默认同样关闭。启用任何自动化交易能力前，请确认自己的使用方式符合适用法律、监管要求、证券公司协议和本人风险承受能力。

## 数据与第三方服务

本项目不会把行情、账户或交易数据上传给项目维护者，具体处理方式见[隐私政策](./PRIVACY.md)。

同花顺、证券公司、交易所、行情提供方、GitHub、Gitee 以及你选择的 AI Agent 或模型均属于独立第三方服务。它们的可用性、数据准确性、收费和规则变化不由本项目控制，相关服务仍适用各自的协议和隐私政策。

## 开源与闭源组件

Agent 入口、配置器、MCP 传输桥和 SDK 等公开源码按照 AGPL-3.0-only 提供。用于连接本机同花顺客户端的原生组件目前只以编译形式发行，适用单独的[原生运行组件许可](./NATIVE_COMPONENT_LICENSE.md)。第三方组件继续适用各自许可证。

如不能接受闭源且尚未使用 Windows 代码签名的本机组件，请不要安装。

## 软件与数据风险

软件按现状提供。第三方客户端更新、网络中断、接口变化、数据延迟或软件错误都可能导致部分功能暂时不可用或结果不准确。

在适用法律允许的范围内，维护者不对因第三方数据错误、软件兼容问题、用户操作、AI 判断、交易决定或第三方服务中断产生的间接、附带或后果性损失承担责任。法律规定不得排除或限制的责任不受本条影响。

## 条款更新

为了安全、合规或功能调整，本条款可能更新。重要变化会在仓库提交记录或发行说明中公布；法律要求另行告知或取得同意的，按相应要求执行。
